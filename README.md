Consolidación y estructuración de una base de datos macroeconómica que integra los principales indicadores de coyuntura de la economía mexicana (INEGI/CONEVAL). Este repositorio sirve como base de datos limpia para la ingesta en modelos econométricos y análisis de series temporales.

Estructuración de Series de Tiempo: Integración de datos trimestrales del Producto Interno Bruto (PIB) desestacionalizado a precios base 2018.

Indicadores del Mercado Laboral: Compilación histórica de la Población Económicamente Activa (PEA) y No Activa basada en la Encuesta Nacional de Ocupación y Empleo (ENOE).

Balanza Comercial: Agrupación de la balanza de pagos (Exportaciones e Importaciones).

Indicadores Sociodemográficos: Clasificación multidimensional de la pobreza (moderada y extrema) a nivel estatal para los años 2018, 2020 y 2022.

Limpieza de Datos (Data Wrangling): Transformación de reportes brutos del Banco de Información Económica (BIE) en formatos tabulares listos para el análisis estadístico en Python/R.
